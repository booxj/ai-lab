# C4 · 游戏题面骨架

- **case-id 示例**：`c4-arcade-loop-001`
- **能力**：游戏（浏览器内可玩的小游戏）
- **对应门**：展厅 IV / GAME

## 目标

做一个 30–60 秒能玩明白的小游戏：有明确目标、失败条件、重开方式；键盘与触屏都能玩。

## 受众

路过展厅的陌生人；不读说明，30 秒内知道怎么玩，愿意再玩一局。

## 硬约束

- 单入口 `result.html`，双击可离线打开；不依赖 CDN、远程贴图、在线排行榜。
- 键盘（方向键/WASD）与触屏（滑动或点按）都能操作；不用鼠标悬停作为唯一输入。
- 有分数或进度、结束条件、一键重开；不依赖刷新页面。
- 首屏不显示调试面板；FPS 读数可隐藏。
- `prefers-reduced-motion: reduce` 时降低抖动与粒子，不影响可玩性。
- 体积：入口 ≤ 3 MB，整件作品 ≤ 8 MB。

## 交付物

`result.html`、`preview.png`（1440×900，取局中画面）、`prompt.md`、`meta.json`。

## 验收点

- 打开后 3 秒内可开始；失败后可直接重开。
- 难度有起点与爬升，不是一条直线。
- 触屏 390 宽度不遮挡操作区；无横向滚动。
- 规则、分数、结束语在页内可读，不靠外链说明。

## 禁止

- 不使用未授权角色、贴图、音效、商标。
- 不做“只有画面没有规则”的交互玩具。
- 不把分数写死在 HTML 里冒充动态结果。
