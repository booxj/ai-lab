# C2 · HTML PPT 题面骨架

- **case-id 示例**：`c2-launch-deck-001`
- **能力**：HTML PPT（浏览器内翻页演示）
- **对应门**：展厅 III / DECK

## 目标

为一个虚构项目做 6–8 页的浏览器演示稿，能在全屏下用键盘左右翻页；每页只讲一件事。

## 受众

会议室里的 6–10 人；投影或笔记本全屏观看，3 米外能看清标题与关键数字。

## 硬约束

- 单入口 `result.html`，双击可离线打开；不依赖 CDN、外链字体、远程图表库。
- 固定 16:9 画布，窗口缩放时不裁切、不出现滚动条。
- 键盘 `←` / `→` / `Space` 可翻页，有页码与进度；首屏不显示编辑器 UI。
- 打印或 `reduced-motion` 时不塌陷。
- 体积：入口 ≤ 3 MB，整件作品 ≤ 8 MB。

## 交付物

`result.html`、`preview.png`（1440×900，取封面页）、`prompt.md`、`meta.json`。

## 验收点

- 6–8 页，页页有标题；翻页无白屏、无布局跳动。
- 至少一页用原生 SVG/CSS 画出的图表或示意图，不是截图贴图。
- 数字与单位一致；中文标点、引号、破折号正确。
- 全屏 1440×900 与 390×844 预览均可用（移动端可降级为纵向滚动）。

## 禁止

- 不使用真实公司 Logo、真实财报数据、未授权图片。
- 不把整页做成一张大图。
- 不引入 PPT 编辑器或第三方模板库。
