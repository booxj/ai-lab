# C1 · 网页题面骨架

- **case-id 示例**：`c1-editorial-001`
- **能力**：网页（单页，HTML/CSS/JS）
- **对应门**：展厅 II / WEB

## 目标

为一个虚构产品做一张可在浏览器直接打开的落地页，要求有明确的叙事顺序、首屏冲击力与可读的中文正文。

## 受众

第一次听说该产品的人；在 1440 桌面与 390 手机两种宽度下都能在 5 秒内看懂“是什么、为什么特别”。

## 硬约束

- 单入口 `result.html`，双击可离线打开；不得依赖 `http(s)://`、CDN、外链字体、远程接口。
- 桌面 1440×900 与移动 390×844 无横向滚动。
- 首屏关键内容不依赖 JavaScript 才可见。
- `prefers-reduced-motion: reduce` 下关闭视差、自动播放与大幅位移动画。
- 体积：入口 ≤ 3 MB，整件作品 ≤ 8 MB。

## 交付物

`result.html`、`preview.png`（1440×900）、`prompt.md`、`meta.json`；字段见 `docs/CONVENTIONS.md`。

## 验收点

- `file://` 打开无报错；刷新两次表现一致。
- 1440 与 390 首屏截图各一张（仅 `preview.png` 入库，移动图可选）。
- 正文可读性：行长、对比度、焦点态、键盘 Tab 顺序。
- 至少有一个“只属于这个题面”的视觉决策，不是通用模板换色。

## 禁止

- 不复制真实品牌官网、不使用未授权字体/图片。
- 不把作品做成“组件库演示页”。
- 不在页面里加载远程统计、追踪脚本。
