# C3 · HTML 短片题面骨架

- **case-id 示例**：`c3-aurora-film-001`
- **能力**：HTML 短片（CSS/JS 驱动的动态影像）
- **对应门**：展厅 I / VIDEO

## 目标

做一个 8–12 秒、可循环播放的浏览器短片：有镜头语言、有节奏、有情绪落点；不是 UI 动效合集。

## 受众

在展厅大屏或手机上无意点开的人；3 秒内被抓住，12 秒内看完一个完整小叙事。

## 硬约束

- 单入口 `result.html`，双击可离线打开；不加载远程视频文件、不依赖 CDN。
- 画面用 HTML/CSS/SVG/Canvas 现场渲染；允许同目录内 `assets/` 图片，但不允许外链。
- 8–12 秒自动循环；有“重播”与“暂停”控制；默认静音。
- `prefers-reduced-motion: reduce` 时降级为静态关键帧或慢速播放。
- 体积：入口 ≤ 3 MB，整件作品 ≤ 8 MB。

## 交付物

`result.html`、`preview.png`（1440×900，取最有代表性的一帧）、`prompt.md`、`meta.json`。

## 验收点

- 循环接缝不闪白、不跳帧；首帧与末帧可衔接。
- 至少三个镜头段落，有明确的景别或运动变化。
- 文字（若出现）在 390 宽度可读，不压在主视觉上。
- 帧率读数如实写进 `meta.notes`；不在真机上宣称未测的数据。

## 禁止

- 不使用未授权影片片段、音乐、配音。
- 不用“粒子爆炸 + 霓虹渐变”充当叙事。
- 不自动播放声音。
